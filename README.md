# KonyaAddFamily

تطبيق أندرويد بسيط لإدارة بيانات العائلات والأفراد، مخصص لتسجيل معلومات الأسر، أفراد الأسرة، الحالات
الخاصة، وعرض الإحصائيات الأساسية مع إمكانية تصدير البيانات إلى ملف Excel.

## فكرة المشروع

يهدف التطبيق إلى تسهيل عملية جمع وتنظيم بيانات العائلات داخل قاعدة بيانات محلية على الهاتف، بحيث
يمكن للمستخدم:

- إضافة عائلة جديدة.
- تسجيل بيانات الأب والزوجة.
- إدخال عدد أفراد العائلة وتصنيفهم حسب العمر والجنس.
- إضافة أفراد تابعين لكل عائلة.
- تسجيل الحالات الخاصة مثل: مريض، جريح، شهيد، أسير، يتيم.
- عرض قائمة العائلات.
- عرض أفراد كل عائلة.
- البحث والتصفية داخل قائمة الأفراد.
- تصدير بيانات العائلات والأفراد إلى ملف Excel.

## نوع المشروع

تطبيق Android Native باستخدام لغة Java.

## التقنيات المستخدمة

- Java
- Android Studio
- XML Layouts
- SQLite Database
- ViewBinding
- RecyclerView
- Material Design
- Apache POI لتصدير البيانات إلى Excel
- Gradle Kotlin DSL
